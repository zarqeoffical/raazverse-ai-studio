# RAAZVERSE AI STUDIO

Free-first starter for preparing original Hindi YouTube Shorts.

## Current version
This repository includes a GitHub Actions workflow that assembles a vertical MP4 from your own images and narration audio. It creates a downloadable artifact for review.

## What it does not do yet
- It does not autonomously research topics or write verified scripts.
- It does not generate Hindi narration or AI video clips.
- It does not publish to YouTube.
- It cannot guarantee views or subscribers.

We will add capabilities in stages and keep publishing approval-based until tested.

## Add your content
- Put 3–8 original or properly licensed images in `assets/images/`.
- Put your narration at `assets/audio/narration.mp3`.
- Optionally add subtitles in `content/captions.srt`.
- Edit `content/metadata.json` with your title and description.

## Run the video builder
1. Open the repository's **Actions** tab.
2. Select **Build Short Video**.
3. Choose **Run workflow**.
4. When it finishes, download the `raazverse-short-video` artifact.
5. Watch the complete video and check facts, spelling, audio, subtitles and rights before publishing.

## Free-tier note
GitHub Actions has usage and artifact limits. Review the current GitHub documentation:
- https://docs.github.com/en/actions/concepts/billing-and-usage
- https://docs.github.com/en/actions/reference/limits

## Copyright and quality
Use original scripts, narration, visuals and music, or assets you have permission to use. Avoid repetitive, mass-produced videos with little original value. Review YouTube's monetization policy:
https://support.google.com/youtube/answer/1311392
